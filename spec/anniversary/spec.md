# 纪念日 需求规格说明

> 状态：已确认
> 创建日期：2026-08-03
> 所属里程碑：M3

## 1. 概述

### 1.1 功能简述
团子记住情侣的纪念日并主动参与：提前一天提醒并生成祝福语，当天主动弹窗庆祝、解锁限时装扮、邀请互赠礼物。让仪式感自动化，同时保留"人"的参与。

### 1.2 所属模块
`core/anniversary.py`（管理、触发、祝福生成）、同步层事件 `date.add` / `date.remind`、`06-数据模型` 中 `anniversaries` 表。

## 2. 用户故事与场景

### 2.1 目标用户
已配对的情侣双方。价值在于"有人替我们记住特别的日子"。

### 2.2 用户故事
- 作为用户，我希望团子提醒我纪念日，以便不因忙碌而错过。
- 作为用户，我希望祝福语由团子口吻生成，以便更有"仪式感"且不显刻意。
- 作为用户，我希望纪念日只在我和 TA 之间可见，以便隐私受保护。

### 2.3 使用场景
1. **提前预告**：距离"在一起 100 天"还有 1 天，团子主动说"后天是特别的日子，要我帮你准备个小惊喜吗？"。
2. **当天庆祝**：纪念日当天双方团子一起弹窗庆祝，解锁限时"纪念日套装"，邀请互赠礼物。
3. **自定义纪念日**：用户添加"第一次约会"或农历纪念日（如七夕、农历生日）作为纪念日，双向同步到对方。

## 3. 功能需求

### 3.1 输入
- 用户操作：添加纪念日（标题、日期、历法类型（公历/农历）、重复方式、提前提醒天数）、修改/删除。
- 系统输入：当前日期、本地 LLM（祝福语生成）。

### 3.2 输出
- 提前提醒（LLM 祝福语 + 团子预告）。
- 当天庆祝弹窗、限时装扮解锁、互赠邀请。
- 对方同步的纪念日提醒事件。

### 3.3 核心行为描述
1. **数据管理**：支持添加/编辑/删除纪念日，字段包括唯一标识、标题、日期、历法类型（公历/农历）、重复方式（一次性/每年）、提前提醒天数。
2. **本地每日检查**：每日零点后检查纪念日列表（无需联网）；距离提醒日等于提前天数时生成祝福并预告；距离为 0 时触发当天庆祝。
3. **祝福生成**：由本地 LLM 按"团子口吻、简短"的约束生成祝福语；祝福风格可配置（卖萌/深情等），风格作为提示词约束传入；生成失败或超时用预设模板兜底。
4. **当天庆祝**：本端弹窗庆祝动画、解锁限时装扮（有有效期，失效后回归原始装扮）、邀请互赠礼物；自动向对方发送纪念日事件，双方团子一起庆祝。
5. **日历同步**：添加/修改纪念日后向对方同步事件；两端列表以"最新时间戳为准"合并；单机未配对时不外发。
6. **隐私**：纪念日属敏感信息，全部加密同步，中继不可见。
7. **联动**：纪念日当天基础互动（带话/共同对话/喂食摸头/连续登录）在养成模块中按双倍积分，互赠礼物按纪念日特惠 +20（数值基准见 pet-growth spec 积分来源表）。

### 3.4 业务规则与约束
- 提醒仅面向本人与对方，不群发。
- 标题支持自定义；默认提供常用纪念日类型。
- 每天仅触发一次提醒与一次庆祝。
- 限时装扮在纪念日当天解锁、按设定天数后自动失效，失效后回归原始装扮。

## 4. 非功能需求

### 4.1 性能要求
- 每日检查为本地轻量操作，无网络开销。
- 祝福生成不超过 3 秒，超出走模板兜底。

### 4.2 安全要求
- 纪念日数据加密同步；中继无法读取。
- 本机数据存储于本地 SQLite，无云端副本（除非用户选择密文备份）。

### 4.3 兼容性要求
- 日期处理遵循本地时区。
- 与主项目日程/提醒模块风格一致（如有）。

## 5. 边界与限制

### 5.1 明确包含（In Scope）
- 纪念日 CRUD、重复方式、提前提醒。
- 公历/农历双历法支持。
- 每日本地检查与触发。
- 祝福语生成（LLM + 模板兜底）、祝福风格可配置（卖萌/深情）。
- 当天庆祝、限时装扮、互赠邀请。
- 日历事件同步与合并。
- 纪念日当天养成双倍积分联动。

### 5.2 明确排除（Out of Scope）
- 农历以外的其他历法（伊斯兰历、佛历等）与节气日历自动排期（基础农历换算含闰月仍支持）。
- 与其他日历应用（系统日历、Google Calendar）同步。
- 群组庆祝或公开纪念日。

### 5.3 已知约束
- 依赖本地 LLM 生成祝福，若模型未加载则走模板。
- 纪念日同步需配对状态；未配对时为纯本地。

## 6. 验收标准（Acceptance Criteria）

- **Given** 已添加"在一起 100 天"且提前 1 天提醒；**When** 到达提醒日；**Then** 团子主动预告并生成祝福语。
- **Given** 当天是纪念日；**When** 系统每日检查；**Then** 本端弹窗庆祝、解锁限时装扮、并向对方发送庆祝事件。
- **Given** 用户在 A 端添加纪念日；**When** 同步；**Then** B 端列表出现同一纪念日，且双方一致。
- **Given** 本地 LLM 生成祝福失败；**When** 触发提醒；**Then** 使用预设模板兜底，不阻塞提醒。
- **Given** 中继存在（**中继模式，M3 专属验收**；M2 以局域网直连抓包验证）；**When** 抓取流量；**Then** 纪念日内容以密文传输，无法读取。
- **Given** 用户添加农历纪念日（如七夕）；**When** 系统每日检查；**Then** 按农历换算为当年公历日期后触发提醒与庆祝。
- **Given** 用户选择"深情"祝福风格；**When** 生成祝福语；**Then** 输出深情风格文案（卖萌/深情可切换）。
- **Given** 限时装扮有效期结束；**When** 系统检查；**Then** 装扮自动失效并回归原始装扮。
