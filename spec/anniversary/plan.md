# 纪念日 实施计划

> 关联 Spec：[[7-AI学习/11-AI桌宠情侣互联/spec/anniversary/spec.md|spec/anniversary]]
> 创建日期：2026-08-03
> 状态：已完成（G1/S1-S5/C1/C2 全部落地，65 单测 + 联调绿）

## 1. 技术方案概述

纪念日是 M3 模块：团子记住纪念日并主动参与。核心链路：本地 `anniversaries` 表（CRUD）→ 每日零点后本地扫描 → 农历纪念日先换算当年公历日期 → 距离提醒日等于提前天数则 LLM 生成祝福预告（模板兜底）→ 距离为 0 则当天庆祝（弹窗 + 解锁限时装扮 + 邀请互赠 + `date.remind` 加密发送对方）→ `date.add` / `date.remind` 双向同步按最新时间戳合并 → 注册 `is_anniversary_today()` 钩子供 pet-growth 积分加成调用。

隐私核心：纪念日属敏感信息，全程加密同步、中继不可见；未配对时纯本地不外发。祝福生成复用主项目 LLM（失败/超时 3 秒走模板兜底），风格可配置（卖萌/深情）。

## 2. 技术决策

### 2.1 方案选型

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 数据存储 | `anniversaries` 表（id/title/date/calendar/repeat/notify_days_before/updated_at），本端读写 | spec 已定；data-consistency 已建表 |
| 农历换算 | 引入 **`lunarcalendar`**（纯 Python、轻量、含闰月，支持 1900-2099） | spec §5.2 已定"基础农历换算含闰月仍支持"；自研换算表易错，成熟小库更稳 |
| 触发机制 | 每日零点后本地扫描（无网络依赖），按"距离提醒日 == notify_days_before / == 0"两级判定，每日每纪念日仅触发一次 | spec 已定；记录"今日已触发"防重复 |
| 祝福生成 | 复用主项目 LLM（团子口吻、≤20 字），风格作为提示词约束；**3 秒超时 / 失败走模板兜底** | spec 已定；模板兜底不阻塞提醒 |
| 限时装扮 | 当天解锁（记录 item_id + expire_at），每日检查校验过期并回归原始装扮 | spec 已定；视觉资源按 08 排期 |
| 同步合并 | `date.add` / `date.remind` 加密双向同步；同 id 以最新 `updated_at`/ts 为准（LWW） | spec 已定；与 data-consistency 冲突合并一致 |
| 养成联动 | 实现并注册 `is_anniversary_today()` 钩子（pet-growth 注入点） | pet-growth plan 已定；当天积分 ×2 / 礼物 +20 由 pet-growth 侧结算 |
| 互赠邀请 | 当天庆祝发送"邀请互赠"信号转交 gift-exchange（事件/回调），礼物流程由该模块实现 | 解耦：gift-exchange 开发顺序在后，不阻塞本模块 |
| 隐私 | 未配对不发送任何纪念日事件；已配对全部走密文 | spec 已定 |

### 2.2 外部依赖

| 依赖 | 用途 | 新增 |
|------|------|:---:|
| `lunarcalendar` | 农历 → 当年公历换算（含闰月） | **本次新增**（纯 Python，无系统依赖） |

| 08 美术资源规划 | 限时装扮视觉资源占位 | 复用 |

### 2.3 内部依赖

- **事件注册表**：`date.add` / `date.remind` 已在 sync-security 登记，本模块消费。
- **data-consistency**：`anniversaries` 表 schema 由 0001 基线定义；断网事件经离线队列补发。
- **pet-growth 钩子**：`is_anniversary_today()` 由本模块实现，在初始化时注册；注册前 pet-growth 默认无加成。
- **gift-exchange 接口**：当天庆祝通过事件/回调发出"邀请互赠"，礼物流程由 gift-exchange 实现（本模块不依赖其落地）。
- **配置**：祝福风格（卖萌/深情）、模板文案、限时装扮时长（默认天数）、每日检查触发时刻（零点后）。

## 5. 测试标准

### 5.1 单元测试标准

- **CRUD**：添加/编辑/删除；非法字段（空标题、非法日期、非法 calendar/repeat）拒绝；默认类型预设。
- **农历换算**：公历/农历互转；闰月用例；边界年份（1900/2099）；农历纪念日换算当年公历日期正确。
- **每日检查**：提醒日与当天两级判定；yearly 重排；每日仅触发一次。
- **祝福生成**：LLM 成功；失败/超时模板兜底；风格切换（卖萌/深情）。
- **限时装扮**：解锁 → 设定天数后失效 → 回归原始装扮。
- **同步合并**：date.add LWW（同 id 最新 ts）；删除同步；未配对不外发。
- **钩子**：今天有/无纪念日判定正确；注册后 pet-growth 加成生效。

### 5.2 集成 / 场景验证标准

- **前置条件**：sync-security、data-consistency、pet-growth 联调通过，双端配对在线，主项目 LLM 可用（不可用走模板兜底）。
- **步骤**：A 添加"在一起 100 天"（提前 1 天）→ B 端列表同步一致 → 模拟到达提醒日前一天 → 双方预告 + 祝福 → 模拟当天 → 双方庆祝弹窗 + 限时装扮 + 邀请互赠 → 当天互动养成分双倍 → 添加农历纪念日（七夕）→ 换算触发 → 限时装扮过期回归。
- **期望结果**：提醒、庆祝、同步、联动、农历、限时全链路正确，抓包仅见密文。
- **异常场景**：LLM 失败模板兜底；未配对本地可用不外发；断网同步延迟补发；限时装扮到期回归。

## 6. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| LLM 未加载 / 生成超时 | 无祝福文案 | 3 秒超时 + 模板兜底，不阻塞提醒（spec 已定） |
| 农历换算库边界用例出错 | 农历纪念日触发偏差 | 选择成熟纯 Python 库（lunarcalendar）；单测覆盖闰月与边界年份 |
| 限时装扮视觉素材缺失 | 装扮展示异常 | 占位图兜底（08 排期 M3 内测前替换） |
| 断网时同步延迟 | 对方看不到新增纪念日 | 离线队列补发；未配对纯本地不阻塞 |
| 时区处理错误 | 提醒/庆祝日期偏移 | 统一按本地时区处理日期（spec §4.3） |
| 邀请互赠依赖 gift-exchange 未落地 | 庆祝时无礼物入口 | 仅发信号不依赖落地；gift-exchange 上线后自动接通 |
| 每日检查重复触发 | 多次提醒/庆祝 | "今日已触发"标记 + 每日仅一次约束（spec §3.4） |
