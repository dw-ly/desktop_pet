# 情绪同步 实施计划

> 关联 Spec：[[7-AI学习/11-AI桌宠情侣互联/spec/mood-sync/spec.md|spec/mood-sync]]
> 创建日期：2026-08-03
> 状态：已确认

## 1. 技术方案概述

情绪同步是**最轻量的互联模块**：本端情绪系统（复用主项目 07）周期输出 → `mood_export` 汇总为当前标签 → **节流判定**（显著变化 + 最小间隔）→ 加密发送 `mood.sync` → 对方解析后映射为团子空闲表现并更新状态条。隐私核心：**只同步三个数值（valence / arousal / label），绝不携带任何文本**；情绪标签不持久化，仅保留当前值。

隐身模式是本模块的最高优先级开关：开启即停止发送并清除本端已展示的对方状态，但不主动回撤对方已收到的标签（避免界面闪烁，由下一次 `mood.sync` 覆盖）。已决议的初始参数：**显著变化阈值 0.3、表现映射人工设计先行**。

## 2. 技术决策

### 2.1 方案选型

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 情绪来源 | 复用主项目 07 情绪系统的连续值（valence / arousal）与标签（EMOTION_MAP，8 标签） | spec 已定；不重复实现识别算法 |
| 汇总周期 | 订阅情绪系统更新事件，本地周期采样（默认 5 分钟）取当前主导标签 | 标签反映一段时间的状态而非瞬时值 |
| 节流 | **双条件**：valence/arousal 任一变化 ≥ **0.3**（初始值）**且**距上次同步 ≥ **10 分钟**才发送 | 决议参数；避免高频同步与抖动 |
| 事件负载 | 仅 `valence`、`arousal`、`label` 三字段，状态覆盖型（无过期语义） | 隐私边界：不携带用户文本 |
| 表现映射 | **人工设计映射表**（8 标签 → 空闲动画表现标识），M2 硬编码表 | 决议；内测后视数据决定是否调整 |
| 本地交互优先 | 接收端仅在团子空闲时应用对方情绪表现，本地交互进行中不覆盖 | spec 已定；低打扰原则 |
| 状态条 | 显示对方在线状态 + 最近标签文字（软化文案如"TA 今天有点累"） | 只显示标签，不显示原文 |
| 隐身模式 | 开启即停发 + 清除本端对方状态；已发标签不主动回撤 | spec 已定；避免界面闪烁 |
| 持久化 | **不写数据库**，标签仅存内存当前值，新值覆盖旧值 | spec 已定；与 data-consistency 对齐（events 表只留日志） |

### 2.2 外部依赖

| 依赖 | 用途 | 新增 |
|------|------|:---:|
| 主项目情绪系统（07） | valence/arousal 连续值与 EMOTION_MAP 标签 | 复用 |
| 主项目动画状态机（07） | 对方情绪表现驱动（空闲动画切换） | 复用 |

| — | 新增第三方库 | 无 |

### 2.3 内部依赖

- **事件注册表**：`mood.sync` 已在 sync-security 注册，负载字段（valence/arousal/label）与 spec 一致。
- **同步层接口**：发送 `mood.sync` 事件、注册接收 handler、查询连接状态（是否已配对在线）。
- **配置**：采样周期（5min）、显著变化阈值（0.3）、最小间隔（10min）、隐身默认关闭。
- **表现映射表**：模块内维护 8 标签 → 动画表现标识，与主项目动画状态机约定衔接。

## 5. 测试标准

### 5.1 单元测试标准

- **情绪汇总**：主导标签选取；连续值 → 标签映射正确。
- **节流判定**：显著变化阈值边界（恰好 0.3）；最小间隔边界（恰好 10 分钟）；无变化不发送。
- **发送负载**：仅包含 valence / arousal / label，断言不含任何文本字段。
- **表现映射**：8 标签映射完整；本地交互优先（空闲检测）。
- **隐身**：开启即停发；清除本端对方状态；已发标签不主动回撤。

### 5.2 集成 / 场景验证标准

- **前置条件**：sync-security 联调通过，双端配对在线，主项目情绪系统与动画状态机可用（不可用时以文字状态条降级验证）。
- **步骤**：A 情绪由开心转疲惫（变化 ≥ 0.3）→ B 收到标签 → B 团子出现对应空闲表现 → B 本地交互时表现暂停 → 恢复空闲后继续 → A 开隐身 → B 不再收到更新 → B 状态条显示"TA 开启了隐身" → A 关隐身 → 恢复同步。
- **期望结果**：标签同步、表现映射、隐身开关全链路正确；事件负载不含文本。
- **异常场景**：情绪无显著变化不发送；节流期间变化不发送；本地交互不被打断。

## 6. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 情绪标签不精确（反映本端判定） | 对方感知偏差 | 设计上接受；状态条用软化文案（"TA 今天有点累"） |
| 表现映射突兀/出戏 | 影响体验 | 动画状态机用渐变过渡；M2 内测后按反馈调优映射表 |
| 状态条泄露情绪隐私 | 用户不适 | 隐身开关 + 只显示标签不显示原文；标签可随时关闭 |
| 主项目动画状态机未就绪 | 表现无法驱动 | 文字状态条降级，表现层可独立验收 |
| 节流导致标签滞后 | 对方看到的非实时状态 | 状态覆盖型设计：显示"最近标签"而非实时，接受延迟 |
